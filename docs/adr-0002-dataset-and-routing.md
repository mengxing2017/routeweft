# ADR 0002：城市级数据集与连续坐标路由

状态：已采用。替代 ADR 0001 中“仅内存节点查询”的实验接口定位。

1. **模块**：domain/dataset/preprocess/routing/daemon 分工；只在引入实际实现时建立 crate。公开 Engine 与 P0 NodeEngine 分开，后者仅用于独立小图算法回归。
2. **格式**：v1 采用 UTF-8 JSON 图和 manifest，SHA-256 校验，受控文件名；不使用 mmap、Rust 内存转储或 C++ 二进制。牺牲部分体积与加载性能换取首期可审计性。未来二进制编码需新格式版本。
3. **构建**：有上限的全内存 PBF 导入，raw/zlib wire 解码；当前不是全国级流式外存构建器。稳定 OSM ID 排序、固定 profile 和可定位输入保证核心图字节确定性。
4. **限制**：禁止边序列 + 前缀自动机，支持重叠模式与后缀回退。only 的每个 via-way 前缀约束出口；相同前缀允许出口先取并集再展开禁止项。无法解析的相关静态限制拒绝构建，条件限制保守删路。
5. **端点**：局部平面吸附，选择最近位置（1 cm 距离容差）内有限方向候选。仅保留最多 16 候选，默认 8；复杂同位多层歧义需要消费者定位/未来 heading 能力，当前没有高度识别。
6. **途经点**：统一分层 Dijkstra 保留限制历史；只能沿原方向通过边中点，不在边中途隐式掉头。节点掉头若未被限制可行，不额外收费。当前成本模型不含道路偏好或转向惩罚。
7. **预算**：工作量、状态、队列、几何数量以及 deadline/取消；库不创建后台任务。基础图与索引受加载上限约束，不声称精确字节级 RSS 配额。
8. **公开发布**：保持 publish=false；项目许可证、支持矩阵、版本兼容和数据来源在发布前单独复核。
